# 🧠 LÓGICA DE ONBOARDING — JEO PERFORMANCE APP

Este documento define a inteligência por trás do fluxo inicial do usuário. O objetivo é coletar dados e direcionar o aluno para o treino e produto ideal.

---

"Bem-vindo à Elite. Antes de começarmos a sua transformação, o Soba precisa de te conhecer. Estás pronto para o nível Hardcore?"

### 1. Perfil Biológico
*   **Nome:** [Texto]
*   **Idade:** [Número]
*   **Peso atual (kg):** [Número]
*   **Altura (cm):** [Número]

### 2. Condição de Saúde (Filtro de Segurança)
*   **Pergunta:** "Possui alguma destas condições?"
    *   ( ) Anemia Falciforme
    *   ( ) Lesão na Coluna/Articulações
    *   ( ) Gestante 🤰
    *   ( ) Nenhuma / Saudável

### 3. Nível de Experiência
*   **Pergunta:** "Como avalia o seu nível atual?"
    *   ( ) Iniciante (Nunca treinei ou estou parado há meses)
    *   ( ) Intermediário (Treino 2-3x por semana com consistência)
    *   ( ) Hardcore (Treino pesado e busco a magnitude máxima)

### 4. Ambiente de Treino
*   **Pergunta:** "Onde será o seu campo de batalha?"
    *   ( ) No Ginásio (Tenho acesso a máquinas e pesos)
    *   ( ) Na Rua/Em Casa (Vou usar o peso do corpo e objetos caseiros)

### 5. Objetivo Principal
*   **Pergunta:** "Qual a sua maior prioridade hoje?"
    *   ( ) Ganhar Massa Muscular (Hipertrofia)
    *   ( ) Perder Gordura (Definição)
    *   ( ) Disciplina e Foco (Mudar a mentalidade)

## ⚙️ FASE 3: MOTOR DE DECISÃO (LÓGICA)

O sistema deve aplicar as seguintes regras automáticas:

| Resposta do Aluno | Direcionamento de Treino | Recomendação de Produto |
| :--- | :--- | :--- |
| **Anemia Falciforme** | Protocolo de Segurança (Descanso longo) | Guia Científico Falciforme |
| **Na Rua/Em Casa** | Sistema de Treino Livre | **Ebook: Guerreiro de Rua** |
| **Ganhar Massa + Baixo Custo** | Plano Hipertrofia A/B/C/D/E | **Ebook: Código do Soba** |
| **Iniciante / Desistente** | Plano Adaptativo | **Ebook: Mente Hardcore** |
| **Gestante** 🤰 | Protocolo Gestação Segura | Guia de Ciência Materna |
